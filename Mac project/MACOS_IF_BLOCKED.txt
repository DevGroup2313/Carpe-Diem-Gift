Carpe Diem on macOS: what to do if the installer will not open
==============================================================

If macOS shows a message like

    "Apple could not verify 'Install Carpe Diem (Mac).command' is free of
     malware that may harm your Mac or compromise your privacy."

then nothing is wrong with the file. This is macOS Gatekeeper. It is not saying
it scanned the file and found something. It is saying it has no proof from Apple
that the file was checked, so it refuses to run it. Any file downloaded from the
internet that has not been through Apple's paid notarization service gets this
treatment, including plain text scripts like this one.

Pick whichever option below suits you.


OPTION 1 (recommended, nothing to disable): run it from Terminal
---------------------------------------------------------------
Gatekeeper guards double-clicking in Finder. It does not stand in the way when
you run the installer yourself in Terminal.

  1. Open Terminal (press Command+Space, type "Terminal", press Return).
  2. Type  cd  followed by a space.
  3. Drag this folder from Finder onto the Terminal window, then press Return.
  4. Type this and press Return:

         python3 install_carpe_diem.py

The setup window opens as normal. Nothing needs to be disabled or approved.


OPTION 2: remove the download quarantine, then double-click
-----------------------------------------------------------
This clears the "downloaded from the internet" flag on this folder only.

  1. Open Terminal.
  2. Type  xattr -dr com.apple.quarantine  followed by a space.
  3. Drag this folder onto the Terminal window, then press Return.

You can now double-click "Install Carpe Diem (Mac).command" normally.


OPTION 3: approve it once in System Settings
--------------------------------------------
  1. Double-click the installer. Let macOS refuse it.
  2. Open System Settings, go to Privacy & Security.
  3. Scroll down. There should be a note about the blocked file with an
     "Open Anyway" button. Click it and confirm.

Note: on some macOS versions you can instead right-click the file and choose
Open. Apple has tightened this over time and the exact wording and steps differ
between macOS versions, so if what you see does not match, Option 1 always works.


Why this happens, briefly
-------------------------
Apple's notarization is a service where software is submitted to Apple, scanned,
and issued a ticket that macOS can check. It requires a paid Apple Developer
account and a Mac to sign and submit from. This installer is a small plain script
and has not been through that process, so macOS has no ticket to check and warns
you. The same warning appears for a great deal of legitimate open source software.

If Carpe Diem is ever distributed more widely, the permanent fix is to build a
proper Mac application and have it signed and notarized. See the README.

UPDATE: two macOS problems fixed, and a simpler alternative
-------------------------------------------------------------------

FIXED 1: On Macs where Python is managed by Homebrew or python.org, the
installer used to fail with "externally-managed-environment". It now tries
three ways automatically and confirms the component actually loads.

FIXED 2: Homebrew's Python ships without Tkinter, so the setup WINDOW could
not open. The installer now does the whole installation in TEXT MODE instead,
in the terminal. Nothing is lost.

SIMPLER ALTERNATIVE (no Python at all):
Carpe Diem is one self-contained file. You do not need this installer.

  Option A - immediate:
    Double-click carpe_diem.html. It opens in Safari and works fully
    offline. This always works.

  Option B - a real app window with the Carpe Diem icon in your Dock:
    1. Put carpe_diem.html online with any free static host
       (e.g. drag the folder onto app.netlify.com/drop, or GitHub Pages).
    2. Open that address in Safari.
    3. File > Add to Dock.
    It then behaves like a native app, with its own window and the sigil
    icon, and works offline afterwards. No Python, no installer, no
    security prompts.
